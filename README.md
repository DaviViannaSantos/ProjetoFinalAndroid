# Harry Potter App
Um aplicativo Android desenvolvido em Kotlin que consome dados da API de Harry Potter utilizando arquitetura moderna MVVM e Jetpack Compose.

## API utilizada
* **Nome:** Harry Potter API
* **Endereço Base:** `https://hp-api.onrender.com/api/`
* **O que usamos:** O endpoint `/characters` para recuperar a lista dinâmica de personagens, exibindo nomes, casas de Hogwarts e atores associados.
